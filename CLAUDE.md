# bank-ledger

End-to-end bank ledger project to learn concurrency and practice using mattpocock/skills.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues (`ChanEuJun/bank-ledger`) via the `gh` CLI; a spec is a parent issue and each ticket is a sub-issue. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the repo root plus `docs/adr/`. See `docs/agents/domain.md`.
